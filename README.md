# Excel SQL 批量生成工具 🍄

> 别再手写一百条 UPDATE 了，让代码替你干活 💪

## 🚀 它能干啥

丢一个 Excel 📥 进来，写一条 SQL 模板 ✍️，它还你几百条完整 SQL 📤。适合一切「我有一个表，我要改 N 个人的数据」的场景。

- **📊 铁打的 Excel，流水的 openpyxl** — 直接扒单元格原始值，身份证号休想变成科学计数法
- **📶 边读边播进度** — 大文件不会让你对着一片空白干瞪眼 😰，百分比妥妥走在前面
- **✨ CodeMirror 编辑器** — SQL 关键字有颜色了！空的时候还带 placeholder 提示，有模有样
- **📋 点一下，占位符到手** — 点击 `$column1$ → 姓名` 直接复制带引号的版本，要不要引号你说了算
- **👀 结果先给你看 50 条** — 一万条 SQL 全渲染怕浏览器扛不住 🔥，预览只亮相 50 条，复制/下载才是完整版
- **⚡ 下载不走服务器** — Blob 浏览器端直出，省一趟来回 🏃💨
- **📝 模板自动记日志** — 每次生成的模板都保存到 `sql_log/`，想不起来上周写的啥？翻日志 📂
- **📐 双列/单列随你切** — 布局偏好自动记住，刷新不丢
- **🔌 没网也能跑** — CodeMirror 资源本地化，不依赖任何 CDN

## 🏃 三步上手

### ① 装依赖

```bash
pip install -r requirements.txt
```

### ② 启动

双击 `restart.bat` 🖱️，或者敲：

```bash
python app.py
```

然后打开 http://127.0.0.1:5000 🌐。局域网其他设备用你的 IP + 5000 端口也能访问。

### ③ 开干

1. 拖个 Excel 进去（.xlsx / .xls，最高 100MB）
2. 写 SQL 模板，占位符用 `$column1$` `$column2$` ……

   ```sql
   update user_info
   set name = '$column2$', age = $column3$
   where id_card = '$column1$';
   ```

3. 点「生成SQL」→ 预览 → 复制或下载，完事 🎉

## 🏷️ 占位符怎么玩

| 你看到的 | 你点它一下 |
|---------|-----------|
| `$column1$ → 姓名` | 剪贴板里是 `'$column1$'` ✅ |

字符串要引号就粘贴直接用，数字不要引号就手动删掉 `'`。工具只负责文本替换，引号的锅不背 🙅。

## ❓ FAQ

**Q: 身份证号变成 0 或者 3.1E+17 了？**
A: 不可能 ❌。v1.0 起用 openpyxl 按原始值读，所有数字都当字符串伺候。

**Q: 在别的电脑上用 IP 打开，复制按钮没反应？**
A: 已经换了 `execCommand` 方案，HTTP 环境也没问题 ✅。

**Q: `$column10$` 会不会被 `$column1$` 截胡，替换成 `0$` 这种鬼东西？👻**
A: 不会。替换顺序按占位符长度降序，长的先来，短的后上，井水不犯河水。

**Q: 想换个端口？**
编辑 `app.py` 最后一行，把 `5000` 改成你喜欢的数字 🔢。
