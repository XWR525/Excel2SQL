# Excel SQL生成工具

一个强大的Web工具，帮助你根据Excel文件快速生成批量SQL语句。

## 功能特点

- 📁 **Excel文件解析** - 支持 .xlsx 和 .xls 格式，最多支持100MB文件
- 📝 **SQL模板编辑器** - 带语法高亮的代码编辑器，自动适应高度
- 🔄 **智能占位符替换** - 使用 `$column1$`, `$column2$` 格式，避免与真实字段冲突
- 📊 **数据预览** - 展示前3行数据，支持横向滚动
- 📋 **一键复制占位符** - 点击标签即可复制占位符
- 💾 **SQL模板日志** - 自动保存每次使用的模板到 sql_log 文件夹
- 📥 **文件下载** - 生成的SQL语句可下载为TXT文件
- 🌐 **跨设备兼容** - 通过互联网IP访问时复制功能依然可用
- ✨ **美观UI** - 渐变配色，流畅动画，固定悬浮气泡提示

## 快速开始

### 环境要求

- Python 3.7+
- pip 包管理器

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动服务

```bash
python app.py
```

服务将在以下地址启动：
- 本地访问：http://127.0.0.1:5000
- 局域网访问：http://[你的IP]:5000

## 使用说明

### 1. 上传Excel文件

点击或拖拽Excel文件到上传区域。

### 2. 查看列信息

- 可用占位符会显示为标签，格式为：`column1 → 列名`
- 点击标签可复制 `$column1$` 格式的占位符
- 数据预览展示前3行数据

### 3. 输入SQL模板

在编辑器中输入SQL模板，使用 `$column1$`, `$column2$` 等占位符。

**示例：**
```sql
update table1 set age = $column2$ where name = $column1$
```

### 4. 生成SQL

点击"生成SQL"按钮，工具会自动替换所有占位符。

### 5. 下载文件

预览生成的SQL语句，点击"下载TXT文件"保存结果。

## 占位符规则

- **显示格式**：`column1 → 状态`（界面展示）
- **使用格式**：`$column1$`（SQL模板中使用）
- **复制内容**：点击标签时复制 `$column1$`

这样设计是为了避免与数据库中真实的 `column1` 字段名冲突。

## 技术栈

### 后端
- **Flask** - Web框架
- **pandas** - Excel文件解析
- **openpyxl / xlrd** - Excel文件读写

### 前端
- **CodeMirror** - SQL语法高亮编辑器
- **原生JavaScript** - 无需框架，轻量快速

## SQL模板日志

每次点击"生成SQL"时，当前使用的SQL模板会自动保存到 `sql_log` 文件夹中。

**文件命名格式**：`年月日时分秒毫秒.txt`
- 例如：`20260325173045123.txt`

## 常见问题

### Q: 通过互联网IP访问时复制功能不工作？
A: 已修复！现在使用兼容性更好的复制方法，HTTP环境下也能正常工作。

### Q: 数据库中有名为 `column1` 的字段怎么办？
A: 使用 `$column1$` 格式的占位符，不会与真实字段冲突。

### Q: 支持多大的Excel文件？
A: 支持最大100MB的文件。

### Q: 气泡提示会随页面滚动移动吗？
A: 不会！气泡固定悬浮在页面顶部，不随滚动移动。
